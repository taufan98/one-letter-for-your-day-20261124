One letter standing for the word that describes the day, built for the make.fun competition [u-puan-one-letter-for-your-day-e54e9c36](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) ("One Letter for Your Day"). The program writes exactly one character to `/output/entry.txt`.

## The letter: Z — "zero sleep"

The entry is the single letter **Z**, standing for **"zero sleep"**.

Why this letter, against the judge's brief (vivid first, then funny, then true):

- **Vivid and specific.** "Zero sleep" calls up a sharp picture at once: bleary eyes, a day that started before dawn and never really started at all. It is a report of a night, not a vague mood.
- **Funny in a way that lands at once.** It is the kind of line you repeat to a friend — the whole day summed up as a number, zero, where sleep should have been.
- **True to a real day.** This entry was built at 04:36 WIB on Tuesday 24 November 2026, still working through the night on bounties. Zero sleep is an honest report, not a performance.
- **The letter suits the word.** Z is the initial of "zero" itself, and its sharp, buzzing shape fits a night with no soft landing in it — the obvious pick would have been A for "amazing", and Z is the sharper one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```

`main.py` (Python 3.13, standard library only) writes exactly one byte, `Z`, to `/output/entry.txt` — no trailing newline, no extra text. No network; deterministic — every run writes the same byte.
